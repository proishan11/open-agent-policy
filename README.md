# open-agent-policy
Open Agent Policy is the open-source policy and authorization layer for AI agents: agent identity, scoped delegation, resource policies, approval gates, runtime enforcement, and auditable zero-trust access.

Zero-trust access control for AI agents.

Open Agent Policy is an open-source, vendor-neutral framework for registering
agents, defining policy, issuing scoped grants, enforcing tool/resource access,
and auditing every agent action.
